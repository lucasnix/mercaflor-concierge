# Generated bouquet variants
Ten transparent PNGs in public/products/p01-classic.png through p05-premium.png were created with the built-in image generation tool using the corresponding original p01–p05.webp as edit targets.
Prompt set: preserve species, colors, wrapping, ribbon and photographic angle; Classic uses approximately half the original flowers; Premium adds six matching flowers; whole bouquet centered, transparent background, no text.
These are illustrative size previews, not verified photographs or exact botanical counts. Original Deluxe images are unchanged.
